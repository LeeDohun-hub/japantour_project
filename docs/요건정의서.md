# Japan Tour Project — 요건정의서

## 1. 목적

본 문서는 방한 일본인 관광객을 대상으로 하는 한국 여행 플래너 및 AI 가이드 서비스의 업무 요건, 기능 요건, 비기능 요건, 데이터 요건을 정의한다. 본 문서는 기본설계서와 상세설계서의 기준 문서로 사용한다.

일본어 버전: [要件定義書.md](./要件定義書.md)

## 2. 서비스 개요

| 항목 | 내용 |
| --- | --- |
| 서비스명 | Japan Tour Project |
| 대상 | 한국 여행을 준비하는 일본인 관광객 |
| 제공 가치 | 여행 조건 입력, 일정 생성, 교통·장소·항공·이벤트 안내 |
| 주요 화면 | 플랜 위저드, AI 채팅 |
| 운영 기준 | Django `127.0.0.1:8000` 또는 배포 서버 |

## 3. 사용자 요건

| 사용자 | 요건 |
| --- | --- |
| 게스트 사용자 | 로그인 없이 여행 조건 입력과 플랜 생성 가능 |
| 로그인 사용자 | 세션 기반 채팅 이력, 여행 프로필 저장 |
| 일본인 관광객 | 일본어 중심 UI와 일정 안내 필요 |
| 운영자·개발자 | 외부 API 키, 데이터 인덱스, 평가 스크립트 관리 필요 |

## 4. 기능 요건

| ID | 기능 | 설명 |
| --- | --- | --- |
| FR-01 | 플랜 위저드 | 8단계로 항공, 숙박, 교통, 지역, 예산, 상세 조건 수집 |
| FR-02 | AI 일정 생성 | 입력 조건과 외부 데이터를 바탕으로 일본어 여행 일정 생성 |
| FR-03 | AI 채팅 | 교통, 맛집, 숙소, 쇼핑, 관광, 항공 질문 응답 |
| FR-04 | 질문 분류 | LLM 기반 category/keyword 분류 |
| FR-05 | RAG 검색 | 내부 관광 지식베이스 기반 답변 보강 |
| FR-06 | 장소 검색 | Naver/Google Places 기반 장소 후보 조회 |
| FR-07 | 항공 조회 | ICN/KAC 항공편 조회 |
| FR-08 | 공항 교통 조회 | 인천공항 버스, 택시, 공항철도 API 연동 |
| FR-09 | 지도 표시 | Naver Map 기반 일정 지도, 마커, 장소 카드 |
| FR-10 | 이벤트 추천 | Interpark/NOL, VisitKorea, 공공행사 데이터 활용 |
| FR-11 | 인증 | 이메일, Google OAuth, LINE OAuth 지원 |
| FR-12 | 플랜 공유 | 플랜 스냅샷 저장 및 공유 페이지 제공 |

## 5. 비기능 요건

| ID | 요건 | 내용 |
| --- | --- | --- |
| NFR-01 | 응답성 | 채팅과 플랜 생성은 사용자 진행 상태를 표시해야 한다 |
| NFR-02 | 안정성 | 외부 API 실패 시 fallback 문구 또는 대체 데이터 사용 |

| NFR-04 | 비용 통제 | Google Places와 LLM 호출은 필요 시에만 실행 |
| NFR-05 | 확장성 | FAISS와 pgvector 백엔드를 선택 가능해야 한다 |
| NFR-06 | 다국어 | 한국어/일본어 응답을 지원해야 한다 |
| NFR-07 | 유지보수 | 설계 문서와 API 클라이언트 책임 범위를 분리한다 |

## 7. 외부 연동 요건

| API | 용도 |
| --- | --- |
| OpenAI | 분류, 답변 생성, 임베딩 |
| Naver Maps | 지도 표시, 지오코딩 |
| Naver Search | 장소 후보 품질 보강 |
| Google Places | 장소 검색 선택 연동 |

| VisitKorea | 관광지, 축제, 숙박 정보 |
| JUSO | 도로명주소 검색 |

## 8. 제약 사항

- 외부 API는 승인 상태, 트래픽 제한, 응답 지연에 영향을 받는다.
- 공공데이터포털 API는 서비스별 활용신청이 필요할 수 있다.
- LLM 응답은 검증된 데이터와 프롬프트 규칙으로 보정해야 한다.
- 지도/장소 데이터는 Naver와 Google 간 품질 차이가 있을 수 있다.

## 9. 성공 기준

- 사용자가 8단계 위저드로 여행 조건을 입력하고 플랜을 받을 수 있다.
- AI 채팅이 한국 여행 관련 질문에 카테고리별로 응답한다.
- 항공·공항교통·장소·이벤트 정보가 일정에 반영된다.
- 한국어와 일본어 문서 및 UI 설명이 일관되게 유지된다.
