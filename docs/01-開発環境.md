# Japan Tour Project — 開発環境

> 韓国語版: [01-개발환경.md](./01-개발환경.md)

## 1. 概要

本プロジェクトは、**訪韓日本人観光客**向けの韓国旅行案内チャットボットと、AI Hub 観光日本語コーパスに基づく**データパイプライン**を含みます。リポジトリには `data/` は含まれず、クローン後に別途準備が必要です。

---

## 2. ハードウェア・OS

| 項目 | 推奨 |
|------|------|
| OS | Windows 10/11（PowerShell）、または WSL / Git Bash |
| メモリ | Python・Streamlit・pandas を同時に使う場合 **8GB 以上** 推奨 |
| ディスク | AI Hub 原本・解凍後はデータセットにより **数 GB 以上** の空き推奨 |

## 3. ランタイム・言語・技術スタック

### 3.1 ランタイム

| 項目 | バージョン |

### 3.2 技術スタック（要約）

| 領域 | 技術 | 役割 |
|------|------|------|
| UI | **Streamlit** | 対話型 Web UI（`app_japan_tour.py`） |

| LLM | **OpenAI API**（`openai`） | 日本語・韓国語応答生成 |
| オーケストレーション | **LangChain** | チェーン・実験コード（`src/`） |
| データ処理 | **pandas** | 観光 CSV 前処理・JSONL 変換（`tour_preprocess.py`） |

| 共通 | **python-dotenv**, **requests** | 環境変数、HTTP |
| データソース | **AI Hub** 観光日本語コーパス | 原本取得後 `data/raw/` 等に整理 |
| リポジトリ | **Git** | バージョン管理 |

詳細パッケージ一覧は下記 **5. 主要依存関係** と同じ基準です。

## 6. 環境変数（`.env`）

ルートの **`.env.example`** をコピーして `.env` を作成し、値を入力します（`README.md` 手順参照）。

| 変数名 | 必須 | 説明 |
|--------|------|------|
| `OPENAI_API_KEY` | **はい**（チャット動作） | OpenAI API キー |
| `AIHUB_APIKEY` | いいえ | AI Hub データ取得用（利用する場合） |
| `LANGSMITH_API_KEY` | いいえ | `src/` LangChain 実験時のトレース用 |
| `LANGCHAIN_PROJECT` | いいえ | LangSmith プロジェクト名（未設定時 `japantour`） |
| `DJANGO_SECRET_KEY` | いいえ | Django 本番用シークレット（未設定時は開発用デフォルト） |
| `DJANGO_DEBUG` | いいえ | `true` / `false` |
| `DJANGO_ALLOWED_HOSTS` | いいえ | カンマ区切りホスト（既定 `127.0.0.1,localhost`） |

秘密情報は **リポジトリにコミットしません。**

## 7. データディレクトリの復元

Git には `data/` がありません。次のいずれかで準備します。

| 方法 | コマンド / 参照 |
|------|-----------------|
| ローカルフォルダ | `python setup_data.py --source-dir "<パス>" --force` |
| ローカル zip | `python setup_data.py --source-zip "<パス.zip>" --force` |
| URL zip | `python setup_data.py --download-url "<URL>" --force` |

AI Hub から取得した場合は `DATA_SETUP.md` に従い、原本を `data/raw/` 向けに整理します。

---

## 8. 前処理・実行

| 段階 | コマンド / ファイル |
|------|---------------------|
| 原本 CSV | `data/raw/tour_knowledge.csv`（スキーマは `DATA_PREPROCESSING.md`） |
| JSONL 変換 | `python tour_preprocess.py` → `data/processed/tour_knowledge.jsonl` |
| チャットボット実行 | `streamlit run app_japan_tour.py` |
| Django（任意） | `python backend/manage.py migrate` → `runserver`（ルート `README.md` §5） |

---

## 9. その他モジュール（`src/`, `evaluation/`）

| パス | 説明 |
|------|------|
| `src/chain/rag_chain.py` 等 | 観光質問分類 + LLM 回答（知識ベース検索は今後連携）。メインチャット（`app_japan_tour.py`）とは別パイプライン。 |
| `evaluation/` | Ragas ベース評価スクリプト・サンプル JSON。Japan Tour 用に差し替えれば利用可。 |

チーム内では「製品 1 次 = Streamlit 旅行チャット + データパイプライン」と範囲を固定し、RAG・評価は 2 次課題とするのを推奨します。
