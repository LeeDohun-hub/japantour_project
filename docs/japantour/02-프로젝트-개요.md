# Japan Tour Project — 프로젝트 개요

## 1. 프로젝트 명

**japantour_project** (한국 여행 일본인 안내 챗봇 및 관광 지식 데이터 구축)

---

## 2. 목적

1. **방한 일본인 관광객**이 일본어 또는 한국어로 질문할 수 있는 **여행 안내 챗봇**을 제공한다.  
2. **AI Hub**에서 제공하는 「생성형AI K-Culture 관광 콘텐츠 특화 일본어 말뭉치」 등을 활용해, 챗봇·RAG에 쓰기 좋은 **Q&A 중심 지식베이스**를 로컬 `data/`에 구축한다.  
3. 전처리 결과(`jsonl` 등)와 향후 **검색 증강 생성(RAG)** 연계를 위한 기반을 마련한다.

---

## 3. 범위(Scope)

### 3.1 포함(In scope)

- Streamlit 기반 **대화형 UI** (`app_japan_tour.py`)
- OpenAI Chat Completions를 이용한 **일본어/한국어 응답** 및 일본어 응답 시 **한국어 번역** 표시
- `setup_data.py`를 통한 **`data/` 디렉터리 복구**
- `tour_preprocess.py`를 통한 **`tour_knowledge.csv` → JSONL** 변환
- 문서화: `README.md`, `DATA_SETUP.md`, `DATA_PREPROCESSING.md`

### 3.2 제외 또는 미완(Out of scope / 향후)

- 모바일 네이티브 앱, 별도 백엔드 서버(Java/Spring) **필수 구성은 아님**
- `data/` 원본 대용량 파일의 Git 저장
- 메인 챗봇 화면에서 **지식베이스 RAG 자동 검색**까지의 완성(현재 앱은 LLM 직접 대화 중심)

## 4. 이해관계자(예시)

| 역할 | 관심사 |
|------|--------|

## 5. 데이터 소스(요약)

| 소스 | 설명 |
|------|------|
| AI Hub | 데이터셋 예: `dataSetSn=71789` (관광 일본어 말뭉치·QA). 상세는 공식 페이지 및 `DATA_PREPROCESSING.md` |
| 내부 가공 | `data/raw/tour_knowledge.csv` — 질문·답변(일)·선택 한국어 등 |

## 6. 시스템 개념도(현행 1차)

```
[사용자 브라우저]
        ↓
[Streamlit — app_japan_tour.py]
        ↓ HTTPS
[OpenAI API]
```

**데이터 파이프라인(오프라인)**

```
[AI Hub 원본] → 정리 → data/raw/tour_knowledge.csv
        → tour_preprocess.py → data/processed/tour_knowledge.jsonl
        → (향후) 임베딩·벡터DB·RAG 연동
```
