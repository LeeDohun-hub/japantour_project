# 日次報告書 — 2026年06月11日

## 1. 업무내용

位置情報カードをクリックした際にNaverマップへURLが遷移できないバグを含む各種バグ修正
  ・`_clean_vk_ko_name` — VisitKorea 施設名の角括弧・人名注釈を除去
  ・`_filter_ref_data_quality` — anchor・住所なし・座標なし候補の事前フィルタリング
  ・飲食店/カフェ候補を `naver_score` 降順でソート
  ・カード `guideDesc` 先頭の括弧表現を自動除去
  ・`renderedAllPlaces` グローバルSetでクロスデイの飲食店/カフェ重複表示を防止
  ・不要なカード（座標・place・韓国語ラベルがすべてなし）をフィルタリング
  ・不正クエリフィルターのパターンを拡張
  ・トークン積集合チェックによるチェーン店の誤マッチをフィルタリング

## 2. 배운것 / 이해한것

LLMプランの品質はReference Dataの上流フィルタリングが最も効果的
`name_ja`フィールドに韓国語が混在するケースが存在 → 言語判別が必須
Naverローカル検索はarea_hint＋トークン一致チェックなしでは誤マッチが多数発生
