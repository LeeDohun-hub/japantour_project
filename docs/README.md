## 2. Project Overview

✅**프로젝트 소개**

방한 일본인 관광객이 일본어 또는 한국어로 질문할 수 있는 **한국 여행 안내 챗봇**과, AI Hub 등 관광 일본어 말뭉치를 활용한 **Q&A 지식베이스(`tour_knowledge`)** 구축을 목표로 한다. 회원·여행자 정보를 반영해 **관광지 추천·일정·문화 안내**를 개인화한다.

✅**프로젝트 필요성**

- 일본어 맞춤 정보와 **문화 간극 설명**이 분산되어 있어, 한곳에서 신뢰 가능한 안내가 필요하다.
- 예산·일정·동선(공항·숙소)에 따라 추천이 달라져야 하므로 **프로필 기반 개인화**가 필요하다.
- 도착 직후 **비행기(공항)에서 숙소까지** 이동은 “가장 빠른 경로 / 가장 저렴한 경로 / 환승이 가장 적은 경로” 등 목적에 따라 안내가 달라져야 한다.
- RAG·출처 표기로 **환각을 줄이고** 관광·교통 등 도메인 지식을 응답에 녹일 수 있다.

## 4. Key Features

① **여행자 정보 기반 맞춤형 안내 챗봇 도입**

회원이 입력한 **여행자 프로필**(성별, 성격, 취미, 고향, 한국에 대한 흥미, 여행 예산, **비행기 출발·도착 시간**, **호텔 예약 유무**, **귀국 시간** 등)을 기반으로 맞춤형 안내·추천을 제공한다.

- 텍스트 입력 외에도 **이미지 인식**(간판·메뉴 등)을 통해 직관적 응답을 제공할 수 있도록 설계한다.

② **여행 성향 유형화(성향 검사) 도입**

여행자의 성향을 MBTI 등으로 유형화하여 성향형 안내를 제공한다.

- 챗봇 응답 시 해당 성향 정보를 반영한 맞춤형 프롬프트를 적용한다.
- 성향 검사를 반복할 때마다 GPT-4o 등이 **새로운 질문지**를 자동 생성한다.
  - 항상 동일한 질문 대신, 일상에서 관찰하기 쉬운 여행·취향 관련 질문으로 구성한다.

③ **대화·프로필 기반 콘텐츠 추천**

TF-IDF 기반 알고리즘과 유사도 분석, 또는 **임베딩·RAG**를 통한 추천 시스템을 구축한다.

- 사용자의 상담·대화 내용과 프로필을 추출하여 관련 **관광 지식 콘텐츠**를 자동 추천한다.
- 정보 탐색과 다음 행동 제안을 동시에 유도한다.

④ **여행 요약 PDF 리포트 제공**

여행 상담·일정 레포트를 다운로드 가능한 **PDF** 형태로 제공하는 기능을 둔다.

- 원하는 날짜·세션의 대화를 요약하여 GPT-4o 등이 자동 생성한 리포트를 제공한다.
- 리포트 형식: **요약, 주의사항(휴무·막차·예약 등), 다음 여행 제안** 등을 포함한다.

⑤ **공항 → 숙소 이동(첫 동선) 안내**

항공 도착 정보와 숙소 위치를 바탕으로, 사용자가 선택하거나 질의에 따라 **가장 빠른**·**가장 저렴한**·**환승이 최소인** 교통편(또는 그 조합·비교)을 제시한다. 실시간 요금·막차 등은 연동 API가 있을 경우 **출처·기준 시각**과 함께 표기한다.

**핵심 이용 흐름(추천 로직)**

`회원가입` → `고객정보 입력` → 위 프로필 항목 반영 → **공항 → 숙소 교통**(가장 빠름 · 가장 저렴 · 환승 최소) → **한국 관광지 추천**

- 도착지 **인천공항** 중심 **거리순** 추천 **또는**
- **숙소(거점)** 기준 거리순 추천

## 5. Model Workflow

① **모델 선정**

| 구분 | 텍스트 전용 모델: Qwen3-8B | 이미지·멀티모달: GPT-4o |
|------|---------------------------|-------------------------|
| **개발사** | Alibaba Cloud | OpenAI |
| **입력값** | 텍스트 | 이미지 + 텍스트 |
| **특징** | 사고 모드(Thinking Mode) 등으로 복합 질문·일정 구성 응답 성능 강화 | 멀티모달 처리로 맥락·의도 파악 정확도 향상, 안내의 공감도·신뢰도 개선 |

② **의미 기반 검색: RAG + 텍스트 임베딩**

- OpenAI의 `text-embedding-3-small` 모델로 문서 임베딩 → **FAISS** 기반 벡터 검색
- 다양한 질문 유형에서 안정적·일관된 검색 성능을 목표로 채택
- 🔗 임베딩 모델 성능 평가 문서(팀 내부 링크 또는 별첨)

③ **질문 유형 분류 & 프롬프트 구조 설계**

- 사용자 질문을 **행동 교정 / 정보 탐색 / 감정 공감** 등으로 분류하는 질문 분류 모델 도입
- 유형별 프롬프트를 설계하여 응답 흐름과 상담 깊이를 확보

④ **장기기억 구조 설계**

- Qwen3-8B 등으로 최근 N턴 대화 요약 후, **ChromaDB**에 사용자 ID 기준으로 기억 저장
- 이후 유사 질문 시 기억을 검색해 프롬프트에 삽입하여 응답에 반영
- user_id 기반 저장·검색이 가능한 **ChromaDB** 활용

## 6. Deployment Pipeline

- **Django** 기반 웹 서비스를 **Docker**로 컨테이너화하고, **AWS EC2·S3·RDS(MySQL)**와 연계하여 인프라를 구성한다.
- **LangChain**과 **RunPod API**를 통해 RAG 기반 챗봇 응답을 제공한다.
