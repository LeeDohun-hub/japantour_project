## 4. KBO 프로야구 일정 
유저에게 여행 일정 중 스포츠 관전을 하고 싶은 경우 그 여행 일정에 맞는 경기 일정을 웹크롤링하여 추천

### 4-1. 문제 분석

| 단계 | 내용 |
|------|------|
| 기존 증상 | "2026년 5월 29일~31일 경기 없음"으로 출력 — 실제로는 경기 있음 |
| 기존 원인 | ASMX 파라미터 오류(`srId=0,1,3,5,7,9`) → HTTP 500 반복, fallback으로 오프시즌 처리 |
| 세션 초반 | 파라미터 순차 발견(`leId` → `srIdList` → `seasonId` → `gameMonth` → `teamId`) |
| ASMX 200 응답 분석 | 응답 형식이 `{"rows": [...]}` (HTML 테이블 JSON) — 기존 파서(`scheduleList`·`gameList` 키 탐색)와 불일치 |

### 4-2. 올바른 파라미터 발견 (KBO 페이지 JS 분석)

BeautifulSoup으로 `https://www.koreabaseball.com/Schedule/Schedule.aspx` HTML을 파싱,  
인라인 `<script>` 태그에서 실제 Ajax 파라미터 확인:

```javascript
var srIdList = "0,9,6"; // 정규시즌
var teamId = "";         // 빈 문자열 (전 구단)
```

기존 코드가 사용하던 `srId=0,1,3,5,7,9`는 실제 KBO 웹사이트와 무관한 값이었음.

### 4-3. `_fetch_kbo()` 전면 재작성

**기존**: ASMX 페이로드 3종 + HTML `<script>` JSON 추출 2단계 시도  
**신규**: 단일 ASMX POST + `_parse_kbo_table_rows()` 파싱

```
POST /ws/Schedule.asmx/GetScheduleList
leId=1&srIdList=0%2C9%2C6&seasonId={year}&gameMonth={mm}&teamId=
```

### 4-4. `_parse_kbo_table_rows()` 신규 메서드

ASMX 응답의 테이블 row 구조 파싱:

| 셀 Class | 내용 | 비고 |
|----------|------|------|
| `day` | `"05.29(금)"` | RowSpan — 날짜 이월 처리 |
| `time` | `"18:30"` | |
| `play` | `"KIAvsLG"`, `"NC1vs5LG"` | `vs` 분리 + 숫자(점수) 제거 |
| `None` (끝에서 2번째) | `"잠실"` | 구장명 |

원정팀-홈팀 순서(`away vs home`): 구장이 홈팀 소속인 것으로 검증.

기존 `_parse_kbo_json()`, `_parse_kbo_html()` 메서드 제거.

### 4-5. `max_per_league` 동적 계산 (`src/chain/router.py`)

기존 고정값 `8` → 여행 기간 일수 × 5 (KBO 하루 최대 5경기 기준):

```python
_days = ((end_d - start_d).days + 1) if (start_d and end_d) else 3
max_per_league=max(8, _days * 5)
```

3일 여행 → 15경기 모두 표시 (기존 8개 제한 → 마지막 날 경기 누락 해소).

### 4-6. 구단별 예매처 URL 대응

기존 `ticket.koreabaseball.com` (접속 불가) → 실제 예매처 3종으로 교체.

| 예매처 | 대상 구단 | URL |
|--------|----------|-----|
| 티켓링크 | LG · 한화 · 삼성 · KT · KIA | `https://www.ticketlink.co.kr/sports/baseball` |
| 인터파크 | 두산 · 키움 | `https://tickets.interpark.com/contents/sports/baseball` |
| SSG 자체예매 | SSG 랜더스 | `https://www.ssglanders.com/ticket/home` |
| 롯데 자체예매 | 롯데 자이언츠 | `https://www.giantsclub.com/contents/ticket` |
| NC 자체예매 | NC 다이노스 | `https://ticket.ncdinos.com/` |

구현:
- 모듈 상단 `_KBO_TICKET_MAP` dict 추가 (홈팀명 → URL)
- `SportsMatch` 데이터클래스에 `ticket_url: str = ""` 필드 추가
- `_parse_kbo_table_rows()`에서 홈팀 기준으로 lookup → 각 경기 객체에 포함
- `fmt_sports_matches()`에서 `m.ticket_url` 사용 (기존 `meta.get("ticket_url")` 제거)
- fetch_failed 폴백 안내문에도 5개 예매처 URL 나열
