# Japan Tour Project — 要件定義書

## 1. 目的

本書は、訪韓日本人観光客向け韓国旅行プランナーおよびAIガイドサービスの業務要件、機能要件、非機能要件、データ要件を定義する。基本設計書および詳細設計書の前提文書として使用する。

韓国語版: [요건정의서.md](./요건정의서.md)

## 2. サービス概要

| 項目 | 内容 |
| --- | --- |
| サービス名 | Japan Tour Project |
| 対象 | 韓国旅行を準備する日本人観光客 |
| 提供価値 | 旅行条件入力、旅程生成、交通・場所・航空・イベント案内 |
| 主な画面 | プランウィザード、AIチャット |
| 運用基準 | Django `127.0.0.1:8000` または本番サーバー |

## 3. ユーザー要件

| ユーザー | 要件 |
| --- | --- |
| ゲスト | ログインなしで旅行条件入力とプラン生成ができる |
| ログインユーザー | セッション、チャット履歴、旅行プロフィールを利用できる |
| 日本人観光客 | 日本語中心のUIと旅程案内が必要 |
| 運用者・開発者 | APIキー、データインデックス、評価スクリプトを管理する |

## 4. 機能要件

| ID | 機能 | 説明 |
| --- | --- | --- |
| FR-01 | プランウィザード | 航空、宿泊、交通、地域、予算、詳細条件を収集 |
| FR-02 | AI旅程生成 | 入力条件と外部データをもとに日本語旅程を生成 |
| FR-03 | AIチャット | 交通、グルメ、宿泊、観光、航空などに回答 |
| FR-04 | 質問分類 | LLMでcategory/keywordを分類 |
| FR-05 | RAG検索 | 内部ナレッジベースで回答を補強 |
| FR-06 | 場所検索 | Naver Local/Mapsから候補を取得 |
| FR-07 | 航空照会 | ICN/KAC航空便を照会 |
| FR-08 | 空港交通照会 | 仁川空港バス、タクシー、空港鉄道APIを利用 |
| FR-09 | 地図表示 | Naver Mapで旅程マーカーとカードを表示 |
| FR-10 | イベント推薦 | Interpark/NOL、VisitKorea、公演データを利用 |
| FR-11 | 認証 | メール、Google OAuth、LINE OAuth |
| FR-12 | プラン共有 | スナップショット保存と共有ページ |

## 5. 非機能要件

| ID | 要件 | 内容 |
| --- | --- | --- |
| NFR-01 | 応答性 | チャット・プラン生成中の状態を表示 |
| NFR-02 | 安定性 | 外部API失敗時にfallbackを使用 |
| NFR-03 | セキュリティ | CSRF、rate limit、セッション保護、秘密情報非コミット |
| NFR-04 | コスト管理 | 外部APIとLLM呼び出しを必要時に限定 |
| NFR-05 | 拡張性 | FAISS/pgvectorを選択可能 |
| NFR-06 | 多言語 | 日本語・韓国語回答をサポート |
| NFR-07 | 保守性 | 文書、APIクライアント、AIルーターの責務を分離 |

## 6. データ要件

| データ | 内容 |
| --- | --- |
| 観光ナレッジ | AI Hubおよび加工済み `tour_knowledge.jsonl` |
| チャット履歴 | `ChatSession`, `ChatMessage` |
| 旅行プロフィール | `TravelerProfile` |
| プランスナップショット | `TravelPlanSnapshot` |
| RAGインデックス | FAISSまたはpgvector |
| 外部API結果 | 航空、交通、場所、イベント |

## 7. 外部連携要件

| API | 用途 |
| --- | --- |
| OpenAI | 分類、回答生成、埋め込み |
| Naver Maps/Search | 地図、ジオコーディング、場所検索 |
| data.go.kr | 仁川空港、空港鉄道、航空、観光・イベント |
| VisitKorea | 観光地、祭り、宿泊 |
| JUSO | 道路名住所検索 |

## 8. 制約

- 外部APIは承認状態、トラフィック制限、応答遅延の影響を受ける。
- 公共データAPIはサービス別の利用申請が必要になる場合がある。
- LLM回答は検証済みデータとルールで補正する必要がある。

## 9. 成功基準

- 8ステップのウィザードから旅程が生成できる。
- AIチャットが旅行カテゴリ別に回答できる。
- 航空、空港交通、場所、イベント情報が旅程に反映される。
- 韓国語・日本語文書が整備されている。
