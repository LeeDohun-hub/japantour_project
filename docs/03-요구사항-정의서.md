Japan Tour Project(요구사항 정의서)

________________________________________

1. 들어가며
1.1 요구사항 정의서의 목적
본 요구사항 정의서는 **방한 일본인 관광객 대상 한국 여행 안내 챗봇**으로 개발하는 「Japan Tour Project」에 대해, 업무 요구사항 및 시스템 요구사항을 명확히 하고 이후 기본설계, 상세설계, 구현의 지침으로 삼는 것을 목적으로 한다.

1.2 대상자
• 방한 일본인 관광객
• 리뷰 담당자(대표, 기획)
• 개발리더(성과물관리)


1.3 개발 전제 조건
• 개발 목적: 방한 일본인 관광객 대상 여행 안내 서비스 구축 및 학습
• 개발 체계: 소규모 팀
• 지원 언어: 일본어, 한국어
• 외부 서비스: OpenAI API, Google Maps Platform, AI Hub
• 데이터셋: AI Hub 「생성형 AI K-Culture 관광 콘텐츠 특화 일본어 말뭉치」 등

________________________________________

2. 시스템 개요
2.1 시스템 명칭
Japan Tour Project(한국 여행 일본인 안내 챗봇)

2.2 시스템의 목적
• 방한 일본인 관광객이 **일본어 또는 한국어**로 한국 여행 관련 질문을 할 수 있도록 한다
• 관광지, 맛집, 교통, 문화 매너, 계절별 옷차림 등을 AI가 안내한다
• 현재 위치 주변 관광지와 카페를 **Google Places API**로 추천한다
• AI Hub의 관광 일본어 말뭉치를 바탕으로 **Q&A 지식베이스(`tour_knowledge`)**를 구축하고, 향후 RAG 연계 기반을 마련한다

2.3 예상 이용 환경
| 구분 | 내용 |
|------|------|
| 이용자(관광객) | 스마트폰, PC의 웹 브라우저 |
| 관리자(운영) | PC의 웹 브라우저 |
| 서버 | Python + Streamlit(메인) / Python + Django(선택형 HTML 프론트 연계 시) |
| 외부 API | OpenAI API, Google Maps Platform(Places API) |

3. 업무 요구사항
3.1 업무 대상
• 방한 일본인 관광객 대상 여행 안내 업무
• 관광 지식 데이터(AI Hub)의 수집 및 정비 업무
• 데이터 전처리 및 Q&A 지식베이스 유지 업무

3.2 업무 흐름
1. 이용자가 브라우저에서 Japan Tour를 실행한다
2. 응답 언어(일본어 / 한국어)를 선택한다
3. 관광, 교통, 맛집 등의 질문을 입력한다
4. 시스템이 OpenAI API에 질의하여 답변을 생성한다
5. 일본어 응답인 경우 한국어 번역을 함께 표시한다
6. 필요 시 현재 위치 또는 좌표를 입력하여 주변 관광지와 카페를 조회한다
7. 운영자는 AI Hub 데이터를 수집 및 정리하여 `data/raw/tour_knowledge.csv`를 유지한다
8. 전처리 스크립트로 `data/processed/tour_knowledge.jsonl`을 생성하고, 향후 RAG에 활용한다

4.1 이용자 구분
| 이용자 | 개요 |
|--------|------|
| 관광객(일반 이용자) | 챗봇에 질문하고 안내 및 추천을 받는다 |
| 운영 담당자 | 데이터 준비, 환경 변수 관리, 배포 운영을 수행한다 |

4.2 권한 개요
• 관광객: 채팅 입력, 응답 언어 전환, 대화 리셋, 현재 위치 기반 주변 검색 이용 가능
• 운영 담당자: API 키 및 `.env` 관리, 데이터 수집 및 전처리, 서버 기동 및 중지가 가능

5. 기능 요구사항
5.1 인증 기능
• 일반 이용자 대상 로그인 인증은 본 범위에서 제공하지 않는다(공개형 챗봇)
• 운영 측은 OS 및 `.env` 파일을 통해 API 키를 보호한다

5.2 채팅 기능(이용자용)
• 일본어 또는 한국어 질문 입력
• 응답 언어 선택(일본어 / 한국어)
• AI(OpenAI `gpt-4.1-mini`) 기반 여행 안내 응답
• 일본어 응답 시 한국어 번역 병기
• 대화 이력 유지 및 화면 표시
• 대화 리셋

5.3 주변 추천 기능(이용자용)
• 브라우저 위치 정보 또는 수동 입력 좌표를 통한 현재 위치 확보
• 검색 반경(미터) 지정
• 관광지(`tourist_attraction`) 조회 및 표시
• 카페(`cafe`) 조회 및 표시
• 평점, 리뷰 수, 거리, 영업 상태 표시
• Google Maps 링크 표시

5.4 데이터 복구 기능(운영자용)
• `setup_data.py`를 이용한 로컬 디렉터리 복구(`--source-dir`)
• 로컬 zip 파일에서 압축 해제(`--source-zip`)
• URL에서 다운로드 후 압축 해제(`--download-url`)
• 기존 `data/` 강제 재구성(`--force`)

5.5 데이터 전처리 기능(운영자용)
• `tour_preprocess.py`를 통한 `data/raw/tour_knowledge.csv` 읽기
• 필수 컬럼(`question_ja`, `answer_ja`) 검증
• 선택 컬럼(`id`, `category`, `area`, `answer_ko`) 유지
• 문자열 앞뒤 공백 제거 및 필수값 공란 행 제거
• `data/processed/tour_knowledge.jsonl` 출력(1행 1JSON)

5.6 선택 UI 기능(Django 연동)
• `frontend/home.html` 및 `frontend/chat.html` 제공
• `/api/health/`를 통한 상태 확인
• `/api/chat/`를 통한 채팅 응답 API 제공

6. 비기능 요구사항
6.1 성능 요구사항
• 동시 이용자 수: 소수 수준(교육·데모 용도)
• 응답 속도: OpenAI API 및 Google Places API 응답 시간에 의존
• 응답 생성 중에는 스피너 등 대기 상태를 표시한다

6.2 보안 요구사항
• API 키(`OPENAI_API_KEY`, `GOOGLE_MAPS_API_KEY`, `AIHUB_APIKEY`)는 소스코드 및 Git에 포함하지 않는다
• `.env` 및 `data/`는 `.gitignore` 대상으로 유지한다
• 입력 검증: Django `/api/chat/`에서는 메시지 길이, 이력 개수, 응답 언어 값을 검증한다

6.3 가용성·유지보수성
• 의존성은 `requirements.txt`로 고정한다
• 데이터 흐름 및 스키마는 `DATA_PREPROCESSING.md`를 기준 문서로 삼는다
• Streamlit은 단일 프로세스 기준이며, 다수 동시 접속에는 별도 배포 설계가 필요하다

7. 시스템 방식·기술 요구사항
7.1 기술 스택
| 구분 | 기술 |
|------|------|
| 언어 | Python(메인) / HTML, CSS, JavaScript(선택 프론트) |
| UI 프레임워크 | Streamlit(메인) / Django(선택) |

| 지도·장소 API | Google Maps Platform(Places API Nearby Search) |
| 데이터 처리 | pandas |

| 버전 관리 | Git |

7.2 시스템 구성
• 프론트엔드(메인): Streamlit Web UI(`app_japan_tour.py`)
• 프론트엔드(선택): HTML/CSS/JavaScript(`frontend/`)
• 백엔드(선택): Django REST API(`backend/`)
• 외부 서비스: OpenAI API, Google Places API, AI Hub
• 데이터 저장: 로컬 `data/`(`raw/`, `processed/`)

9. 제약 조건
• 교육·트레이닝 용도를 포함하므로 기능은 단계적으로 정비한다
• 외부 API(OpenAI, Google)의 이용 요금 및 레이트 제한을 따른다
• AI Hub 데이터의 이용 범위, 재배포 금지 등 플랫폼 약관을 준수한다
• 대용량 데이터는 Git에 포함하지 않고 `setup_data.py` 복구 방식으로 관리한다

11. 목표 정의
• 일본어 또는 한국어로 한국 여행 관련 질문을 입력하고 AI 응답 및 한국어 번역을 확인할 수 있을 것
• 현재 위치 또는 좌표를 기준으로 주변 관광지와 카페 추천이 표시될 것
• AI Hub 관광 일본어 데이터로부터 `tour_knowledge.csv`를 정비하고, `tour_preprocess.py`로 JSONL을 생성할 수 있을 것
• Streamlit / Django 양쪽 구성에서 동작 확인이 가능할 것
• 방한 일본인 관광객 대상 안내 서비스의 개발 및 운영 이미지를 공유할 수 있는 상태일 것
