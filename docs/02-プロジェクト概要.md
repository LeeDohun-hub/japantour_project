# Japan Tour Project — プロジェクト概要

> 韓国語版: [02-프로젝트-개요.md](./02-프로젝트-개요.md)

## 1. プロジェクト名

**japantour_project**（韓国旅行・日本人向け案内チャットボットおよび観光知識データ構築）

---

## 2. 目的

1. **訪韓日本人観光客**が日本語または韓国語で質問できる**旅行案内チャットボット**を提供する。  
2. **AI Hub** が提供する「生成型 AI K-Culture 観光コンテンツ特化日本語コーパス」等を活用し、チャットボット・RAG 向けの **Q&A 中心知識ベース**をローカル `data/` に構築する。  
3. 前処理結果（`jsonl` 等）と将来の **検索拡張生成（RAG）** 連携の基盤を整える。

---

## 2.1 主要ユーザーフロー（企画）

```
会員登録
    → 顧客情報入力
         · 性別、性格、趣味、出身地
         · 韓国への関心
         · 旅行予算
         · 飛行機出発・到着時刻
         · ホテル予約の有無
         · 帰国時刻
    → 空港 → 宿泊施設（初動線）案内
         · 最速 | 最安 | 乗り換え最少（ユーザー選択・質問に応じる）
    → 韓国観光地推薦
         · 到着地 仁川空港 を基準とした距離順
      または · 宿泊（拠点）基準の距離順
```

現行の Streamlit アプリは対話型案内が中心であり、会員 DB・距離順エンジン・全項目 UI は段階的に反映する。発表用の要約・スタックは [README.md](./README.md) を参照。

---

## 3. 範囲（Scope）

### 3.1 含む（In scope）

- Streamlit ベースの**対話型 UI**（`app_japan_tour.py`）
- OpenAI Chat Completions による**日本語/韓国語応答**および日本語応答時の**韓国語訳**表示
- `setup_data.py` による **`data/` ディレクトリ復元**
- `tour_preprocess.py` による **`tour_knowledge.csv` → JSONL** 変換
- 文書: `docs/japantour/`、ルート `README.md`、`DATA_SETUP.md`、`DATA_PREPROCESSING.md`

### 3.2 除外または未完了（Out of scope / 将来）

- モバイルネイティブアプリ、別バックエンド（Java/Spring）の**必須構成ではない**
- `data/` 原本大容量ファイルの Git 保存
- メインチャット画面での**知識ベース RAG 自動検索**までの完成（現状は LLM 直接対話中心）
